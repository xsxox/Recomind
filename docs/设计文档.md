# Recomind 电影智能推荐系统 —— 设计文档

## 1. 项目概述

本项目实现一个基于**自然语言处理（NLP）**与**机器学习（ML）**的电影智能推荐系统。系统以 Python 为主要开发语言，采用 PyQt5 构建桌面图形界面、MySQL 存储业务数据，通过中文分词（jieba）与文本特征提取（TF-IDF、LDA）理解电影内容，并结合内容推荐、物品协同过滤、用户协同过滤三种策略为用户生成个性化推荐，辅以 MMR 多样性重排与推荐解释。

## 2. 系统架构

系统采用分层架构，职责清晰、便于维护：

| 层次 | 目录 | 职责 |
| --- | --- | --- |
| 界面层 | `ui/` | PyQt5 桌面界面（登录、推荐、浏览、详情、数据管理） |
| 服务层 | `services/` | 业务编排：用户/电影/评分/历史/推荐服务 |
| 算法层 | `recommender/` | 内容推荐、物品/用户协同过滤、混合推荐、MMR 重排、解释 |
| NLP 层 | `nlp/` | 文本清洗、jieba 分词、TF-IDF、LDA 主题模型 |
| 数据层 | `db/` | 连接管理、建表 DDL、实体模型、初始化与迁移 |
| 数据采集 | `scripts/` | 从 TMDB 拉取电影、海报、影评；生成模拟评分 |
| 评估 | `evaluation/` | 离线评测指标与评估脚本 |

## 3. 数据库设计

主要数据表如下：

- **users**：用户（id、username、password 哈希、nickname、gender、age、register_time）。
- **movies**：电影（title、director、studio、genre、release_year、description、poster_color、poster_url、tmdb_id、vote_average、vote_count）。
- **ratings**：评分（user_id、movie_id、score、comment、rating_time），`(user_id, movie_id)` 唯一。
- **browse_history**：浏览历史（user_id、movie_id、browse_time）。
- **reviews**：真实影评（movie_id、author、content、rating、created_at，来自 TMDB）。

评分表与浏览历史、影评表均以外键关联 `movies` 与 `users`，删除电影/用户时级联清理。

## 4. 推荐算法设计

### 4.1 内容推荐（Content-Based）

1. 对电影文本（片名 + 导演 + 类型 + 关键词 + 简介）做 jieba 分词、去停用词；
2. 用 `TfidfVectorizer`（词 + 二元词组，ngram_range=(1,2)）构造 TF-IDF 向量；
3. 用 LDA 主题模型（`LatentDirichletAllocation`）抽取文档-主题分布；
4. 将 TF-IDF 余弦相似度与主题余弦相似度按权重加权（`TOPIC_WEIGHT=0.2`）；
5. 对用户偏好（高分电影集合）取相似度均值，推荐语义最相近的电影。

### 4.2 物品协同过滤（Item-Based CF）

- 构建用户-电影评分矩阵，评分做均值中心化以消除个人打分习惯差异；
- 计算物品-物品余弦相似度；
- 对目标用户未评分电影，取其与已评高分电影中相似度最高的 K 个邻居，加权预测兴趣分。

### 4.3 用户协同过滤（User-Based CF）

- 计算用户-用户余弦相似度（同样均值中心化）；
- 取与目标用户最相似的前 K 个邻居；
- 用邻居对某电影评分的加权平均预测目标用户兴趣分。

### 4.4 混合推荐与多样性重排

- 将内容、物品协同、用户协同三类结果分别做最小-最大归一化后按权重融合（内容 0.2 / 物品协同 0.5 / 用户协同 0.3）；
- 再用 MMR（Maximal Marginal Relevance，`MMR_LAMBDA=0.7`）在相关度与多样性之间重排，避免结果雷同。

### 4.5 冷启动与推荐解释

- **冷启动**：新用户无评分时，优先按最近浏览历史做内容推荐，否则返回热门电影；
- **推荐解释**：根据三类来源的贡献选择主导来源，生成自然语言解释（如“与你喜欢的《X》内容相似”“与你口味相近的 N 位用户也喜欢”）。

## 5. 评估方法

采用**随机留出法**：对每位用户随机留出约 20%（至少 1 条）评分作为测试集，其余作为训练集；在训练集上训练模型，为每位用户生成 Top-K 推荐，与留出项对比，计算命中率、精确率、召回率、NDCG、覆盖率与多样性，并与热门基线、随机基线对比。详见 `docs/评估报告.md`。
